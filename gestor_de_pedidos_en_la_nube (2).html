🌐 ¿Dónde encuentro mi enlace de GitHub?

Una vez que subiste tu archivo index.html a GitHub y activaste GitHub Pages, el link web se encuentra exactamente aquí:

Pasos para ver tu enlace:

  1. Entra a tu repositorio en GitHub.com.
  2. Haz clic en la pestaña superior llamada Settings (Configuración con ícono de engranaje).
  3. En el menú de la izquierda, busca la sección Code and automation y haz clic en Pages.
  4. Ahí verás escrito en letras azules el enlace web oficial de tu tienda. ¡Ese es el que debes abrir en el celular de tu mamá!
